# Safora `/docs` — how this folder is organised

```
docs/
  v1/   ← active V1 codebase & submission documentation
  v2/   ← post-V1 production roadmap (no deadline; picks up after V1 ships)
  v3/   ← future research files (AI routing, mesh SOS, AI image detection, evaluation)
  setup.md   ← local dev setup guide
  SAFORA_Synopsis_Formatted.pdf   ← project synopsis document
```

## Reading order
1. `v1/README.md` → `v1/tasks.md` (V1 specifications & delivered features)
2. `v1/architecture.md`, `v1/api.md`, `v1/database.md` (technical design)
3. For post-submission roadmap: `v2/README.md` → `v2/roadmap.md`
4. `v3/README.md` for faculty viva when asked about future research scope (`v3/`).
